# نظام إدارة الأفراد والحضور

نظام متكامل واحترافي لإدارة الأفراد والحضور والغياب والإجازات والمهمات، مصمم للعمل كأداة Offline First على أنظمة Android و Windows Desktop باستخدام Flutter وقاعدة بيانات SQLite محلية.

## الميزات الأساسية
- **إدارة الأفراد:** إضافة، تعديل، وحذف بيانات الأفراد (الرقم العسكري، الاسم، النقطة، الإدارة، الفصيلة).
- **إدارة الحضور:** تسجيل الحضور والغياب والإجازات يومياً.
- **إدارة المهمات والإجازات:** تتبع المهام والإجازات لكل فرد.
- **التقارير:** استخراج تقارير بصيغة PDF و Excel.
- **دعم Offline First:** العمل بالكامل دون الحاجة إلى اتصال بالإنترنت باستخدام قاعدة بيانات محلية (Drift/SQLite).
- **واجهة مستخدم عربية:** واجهة بتصميم عصري (Material 3) تدعم الاتجاه من اليمين لليسار (RTL) بشكل كامل.
- **دعم متعدد المنصات:** تصميم متجاوب يعمل بكفاءة على شاشات الهواتف (Android) وأجهزة الكمبيوتر (Windows).

## التقنيات المستخدمة
- **إطار العمل:** Flutter
- **قاعدة البيانات:** Drift (SQLite)
- **تصدير التقارير:** مكتبات `pdf` و `excel`
- **التصميم:** Material 3 مع دعم `flutter_localizations` للغة العربية.

## طريقة التشغيل

1. تأكد من تثبيت Flutter SDK وتوافر بيئة تطوير Android و/أو Windows.
2. قم بتثبيت الحزم المطلوبة:
   ```bash
   flutter pub get
   ```
3. في حال قمت بتعديل مخطط قاعدة البيانات (Drift)، قم بتشغيل أمر بناء الكود التلقائي:
   ```bash
   flutter pub run build_runner build --delete-conflicting-outputs
   ```
4. قم بتشغيل التطبيق:
   ```bash
   flutter run
   ```

## بناء التطبيق

لإنشاء نسخة مجمعة لأنظمة Windows:
```bash
flutter build windows
```

لإنشاء ملف APK لنظام Android:
```bash
flutter build apk --release
```
